# TinyML / Embedded ML Projects

Machine learning models deployed on microcontrollers. See [ROADMAP.md Phase 4](../../ROADMAP.md).

**Planned projects:**
- Keyword spotting on Arduino Nano 33 BLE Sense
- Vibration anomaly detection (ESP32 + MPU6050)
- Gesture recognition (Raspberry Pi + camera)
- ECG anomaly detection on wearable hardware
- Predictive maintenance on industrial motor

**Tools:**
- TensorFlow Lite
- Edge Impulse
- Arduino IDE / PlatformIO
